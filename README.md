# 🎓 Gestion de Formations

Application de gestion des étudiants, formations et inscriptions développée en Python et SQLite.

## ✨ Fonctionnalités

- **Gestion des étudiants** : Ajouter, modifier, supprimer, enregistrer
- **Gestion des formations** : Créer et organiser les formations
- **Inscriptions** : Inscrire un étudiant à une formation
- **Base de données** : SQLite (`bdd/bdd_gestion_formations.db`)
